# User guide — MageMaclean Core

**Product version:** 1.0.5  
**Audience:** Store administrators

## What Core provides

MageMaclean Core is **not a standalone merchant feature**. It provides shared infrastructure for MageMaclean extensions:

- **MageMaclean** admin menu parent
- Shared ACL resources for child modules
- Configuration tab grouping under **Stores → Configuration → MageMaclean**

## Merchant usage

There is **no separate Core configuration screen** for day-to-day store operations. After installation:

1. Install your MageMaclean feature extension (Additional Emails, Salesrep Commissions, etc.).
2. Use that extension's menu entries under **MageMaclean** in Admin.
3. Configure the feature module under **Stores → Configuration → MageMaclean**.

## Permissions

Core defines the parent ACL resource. Feature modules add granular permissions (view, edit, configuration). Assign those on **System → Permissions → User Roles** when rolling out a new MageMaclean extension.
